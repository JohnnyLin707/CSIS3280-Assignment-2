function readData($fileName){
    $pairs = [];
    // 数据文件放在 inc 的上级目录里的 data 文件夹
    $path = __DIR__ . '/../data/' . $fileName;

    if (!file_exists($path) || !is_readable($path)) {
        return $pairs; // 文件缺失 -> 返回空数组
    }

    $handle = fopen($path, 'r');

    // fgetcsv() 读一行并按逗号拆分
    while (($row = fgetcsv($handle)) !== false) {
        if (count($row) >= 2) {
            $key         = trim($row[0]);
            $value       = trim($row[1]);
            $pairs[$key] = $value;
        }
    }
    fclose($handle);

    return $pairs;
}

为什么要这样写

  • 返回关联数组：['mar' => 'Marketing', 'csis' => 'Computing Science...']，正好喂给 foreach。
  • 用 __DIR__ 而不是 '../data/'：避免"当前工作目录"变化导致找不到文件（最常见的坑）。
  • fgetcsv() 让 .csv 和 .txt 通吃；文件不存在时返回空数组，页面不会崩。
检查点：临时写一句 print_r(readData('department.csv'));，能看到 5 组键值对再往下做。

inc/validate_JLi016.inc.php成品（节选 + 全貌）
require_once __DIR__ . '/utility_JLi016.inc.php'; // 校验 department/courses 要用到数据文件

function validate(){
    $errors = [];

    // check the name
    $name = filter_input(INPUT_POST, 'name');
    if (empty($name)) {
        $errors['name'] = 'Please enter your fullname';
    } elseif (!preg_match("/^[a-zA-Z' -]+$/", $name)) {
        $errors['name'] = 'Name can only contain letters, spaces, hyphens, and apostrophes.';
    } elseif (str_word_count($name) < 2) {
        $errors['name'] = 'Please enter both your first and last name.';
    }

    // check the id
    $pattern = [ "options" => [ "regexp" => "/^\d{10}$/" ]];
    $id = filter_input(INPUT_POST, 'studentID', FILTER_VALIDATE_REGEXP, $pattern);
    if (empty($id)) {          // empty() 同时覆盖 null（没填）和 false（校验失败）
        $errors['studentID'] = 'ID should be ten digit number';
    }

    // check the email
    $email = filter_input(INPUT_POST, 'email', FILTER_VALIDATE_EMAIL);
    if (empty($email)) {
        $errors['email'] = 'Please enter the correct email address';
    }

    // check the term
    $pattern = ["options" => ["regexp" => "/^(Winter|Summer|Fall) 202[0-6]$/"]];
    $term = filter_input(INPUT_POST, 'term', FILTER_VALIDATE_REGEXP, $pattern);
    if (empty($term)) {
        $errors['term'] = 'Please enter the correct term between Winter 2020 until Fall 2026';
    }

    // check the dept
    $dept      = filter_input(INPUT_POST, 'department');
    $deptArray = readData('department.csv');
    if (empty($dept) || !array_key_exists($dept, $deptArray)) {
        $errors['department'] = 'Please select one of the departments';
    }

    // check the course
    $courses = filter_input(INPUT_POST, 'courses', FILTER_DEFAULT, FILTER_REQUIRE_ARRAY);
    $courseArray = readData('courses.txt');
    if (empty($courses)) {
        $errors['courses'] = 'Please select one of the courses';
    } else {
        foreach ($courses as $course) {
            if (!array_key_exists($course, $courseArray)) {
                $errors['courses'] = 'Please select one of the courses';
                break;
            }
        }
    }

    // check the status
    $status = filter_input(INPUT_POST, 'status');
    if (empty($status) || !in_array($status, ['domestic', 'international'])) {
        $errors['status'] = 'Please select one of the statuses';
    }

    return $errors;   // 空数组 = 全部通过
}
两个关键设计：
  • 姓名用 if / elseif / elseif：同一字段一次只报一条，输入 John24 时报的是"字符错误"（与作业截图一致）。
  • 校验 department / courses 时重新 readData() 比对键，能挡住用户伪造 POST 提交不存在的选项值。

坑易错点清单

  1. inc 文件第一行必须是 <?php：把文件头注释写在 <?php 之前，注释会被当成纯文本输出到页面，同时函数未定义导致 Call to undefined function 致命错误。注释要写在 <?php 里面。
  2. FILTER_REQUIRE_ARRAY 放第 4 个参数，放第 3 个读不到数组。
  3. include 路径用 __DIR__：require_once __DIR__ . '/utility_...inc.php'，比相对路径稳。
  4. 服务器要在项目目录启动，否则 URL 对不上；路径含空格要加引号。
  5. empty('0') 为 true（week04 的坑）：本作业学号必须 10 位不涉及 0，但价格/数量类字段判空要先排除 '0'。
  6. 用 elseif 而不是多个 if：同一字段一次只显示一条错误。
  7. 提交前替换文件头的姓名和学号，别把占位信息交上去。
